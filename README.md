# Retail Billing & Inventory Management System

A Python-MySQL based retail billing system with QR Code scanning.

## Features

- Customer Registration
- Product Management
- QR Code Product Scanning
- Automated Billing
- Audit Table Generation
- Customer Purchase History
- Top Selling Product Analysis

## Technologies Used

- Python
- MySQL
- OpenCV
- Pyzbar
- SQL

## Run Project

1. Install requirements

pip install -r requirements.txt

2. Import retail_database.sql in MySQL

3. Update database credentials

4. Run

python main.py
